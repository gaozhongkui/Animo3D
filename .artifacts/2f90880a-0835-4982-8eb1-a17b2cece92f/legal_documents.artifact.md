# Animo3D (Livo 3D) 法律文件 (Refined Version)

**最后更新日期**：2026年8月31日

本文件结合了 **Privacy-First (隐私优先)** 的设计理念与 **AI 生成服务** 的特殊法律要求，为您提供最符合 App Store 审核标准的协议模板。

## 1. 隐私政策 (Privacy Policy)

### 核心理念
**Animo3D** (以下简称“本应用”) 是一款赋予用户 3D 创作能力的工具。我们的核心理念是 **“隐私即核心”**。我们认为您的创意资产和个人媒体属于您自己，因此我们尽最大努力在您的设备本地处理所有数据。

### 1.1 强力数据排他声明 (我们不收集什么)
*   **无个人身份信息 (PII)**：我们不要求您创建账户，不收集您的姓名、电子邮件、电话号码或任何可以识别您身份的信息。
*   **无运营服务器**：我们不运行用于存储用户数据的中心化服务器。您的 3D 模型和录制的视频仅存储在您的设备中。
*   **无数据买卖**：我们不会出售、出租或交易您的媒体数据或使用习惯给第三方。

### 1.2 本地处理与系统权限
*   **端侧动作捕捉 (On-Device Processing)**：当您使用“视频动捕”功能时，本应用使用 Google MediaPipe 框架在您的**设备本地**实时分析人体姿态。**我们不会将您的原始视频上传到任何服务器**。
*   **照片库访问**：仅在您主动选择照片进行 3D 建模或选择视频进行动捕时使用。
*   **相机访问**：仅用于 AR (增强现实) 模式，以便将 3D 角色放置在真实场景中。

### 1.3 必要的三方服务交互 (透明说明)
为了实现核心功能，某些特定操作需要与第三方 API 交互：
1.  **AI 3D 建模 (Tripo3D)**：当您主动点击“生成 3D”时，所选图片将上传至 **Tripo3D.ai** 进行算法处理。这是由您触发的单次定向行为。
2.  **3D 模型搜索 (Sketchfab)**：浏览“发现”频道时，您直接与 **Sketchfab** API 交互。下载模型需遵守其标准的许可和交付协议。

### 1.4 数据保留与删除
*   **无备份恢复**：由于我们不提供云端备份，**如果您删除 Animo3D 应用，所有本地生成的模型和作品将永久丢失**。我们无法为您找回数据。
*   **缓存管理**：您可以通过应用内的“清除缓存”功能随时删除下载的远程资产。

下载或使用 Animo3D，即表示您同意本条款。

### 2.2 AI 生成内容免责声明 (AI Accuracy Disclaimer)
*   **不完美性**：AI 生成的 3D 模型和动捕数据可能存在瑕疵、错误或不准确性（如穿模、纹理异常）。本应用仅作为创意工具提供，不保证输出结果的完美性。
*   **第三方依赖**：AI 生成功能依赖于第三方服务商 (如 Tripo3D)。若三方服务停机或变更条款，可能导致相关功能暂时不可用，本应用对此不承担赔偿责任。

### 2.3 用户内容与权利归属
*   **所有权**：您拥有通过本应用生成的视频和 3D 模型的所有权。
*   **授权限制**：对于从 Sketchfab 下载的模型，您必须遵守其对应的知识共享 (Creative Commons) 或其他授权条款。
*   **合法合规**：您必须确保上传建模的照片已获得相关权利人的许可。严禁生成侵犯他人隐私、肖像权或涉及违法违规的内容。

### 2.4 Pro 会员 (终身解锁)
*   **支付模式**：Animo3D Pro 为一次性买断制，无订阅费。
*   **支付处理**：所有交易均通过 Apple App Store 进行，受 Apple 支付条款约束。
